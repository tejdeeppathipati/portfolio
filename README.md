# Tejdeep Pathipati — Portfolio

Personal portfolio for [tejdeeppathipati.com](https://tejdeeppathipati.com), built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, and Magic UI.

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Portfolio content and links are maintained in `src/data/resume.tsx`.

## Production

```bash
pnpm build
pnpm start
```
